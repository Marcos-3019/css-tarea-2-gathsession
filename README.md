# GathSession — CSS Tarea entregable 2

Proyecto inicial en HTML5 y CSS3, basado en el diseño proporcionado por Conquer Blocks.

## Estructura
- `index.html`: estructura semántica de la página.
- `css/styles.css`: estilos y estados hover.
- `assets/images/`: recursos extraídos del paquete Figma (incluye los originales y copias con nombres descriptivos para los retratos principales).

## Cómo abrir
1. Abre esta carpeta en Visual Studio Code.
2. Abre `index.html` con Live Server (si tienes la extensión) o abre el archivo directamente en el navegador.
3. Compara el resultado con la referencia y ajusta medidas y posiciones.

El CSS inicial es una base de trabajo; la fidelidad final se revisará visualmente contra el PDF/Figma antes de entregar.
